## ごったいって？

月間100万PV！を誇る[タイ語辞書サイト](https://www.gotthai.net)です。
ごったいは、あなたのタイ語学習を応援する、無料で使えるタイ日辞書です。

単語や例文の成り立ちがわかりやすく、ほぼ全てが音声付き！タイ文字や日本語の意味検索はもちろん、発音によるあいまい検索もできます。正確な発音記号・音声が収録されているので、リスニング・スピーキングの練習にも最適。
まじめにタイ語を学習したいという方にオススメです！
